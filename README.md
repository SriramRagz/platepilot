# PlatePilot – AI Breakfast Companion

An AI-powered breakfast recommendation application built using Python, Streamlit, LangChain and OpenAI GPT-4o-mini.

## Features
- Personalised breakfast recommendations
- Vegetarian, Vegan and High Protein preferences
- Ingredient-based recommendations
- Adjustable number of suggestions
- Preparation steps and nutritional highlights

## Technology Stack
- Python
- Streamlit
- LangChain
- OpenAI GPT-4o-mini
- python-dotenv

## Setup

Create a virtual environment:

python3 -m venv .venv
source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Configure your OPENAI_API_KEY environment variable.

Run the application:

streamlit run app.py

## Security
Never upload API keys or .env files to GitHub.
